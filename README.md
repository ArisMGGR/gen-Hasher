# Hasher

A small desktop app that hashes a string. Type or paste text and the digests update as you type; copy any digest with its **Copy** button.

Algorithms: MD5, SHA-1, SHA-224, SHA-256, SHA-384, SHA-512, SHA-512/224, SHA-512/256, SHA3-224, SHA3-256, SHA3-384, SHA3-512.
Text is hashed as UTF-8, and line breaks are hashed as `\n` (pasted Windows `\r\n` line breaks become `\n`). The checked algorithms are remembered between launches.

## Build

Needs JDK 21+, Maven, and (for the installer) WiX Toolset 3 on `PATH`.

```bash
mvn package                   # runs tests, builds target/hasher.jar
java -jar target/hasher.jar   # run it
```

```powershell
powershell -ExecutionPolicy Bypass -File build-installer.ps1   # builds target\installer\Hasher-1.0.0.exe
```

`-ExecutionPolicy Bypass` is needed because Windows blocks local scripts by default; it applies to this one run only.

To build the installer and run it in one step, double-click `install-program.cmd` (or run it from a terminal).

The icon is generated by `java tools/IconGen.java` (run from the project root).
