# Hasher

A small desktop app that hashes a string. Type text, press **Enter** (or **Hash**), and copy any digest with its **Copy** button.

Algorithms: MD5, SHA-1, SHA-224, SHA-256, SHA-384, SHA-512, SHA-512/224, SHA-512/256, SHA3-224, SHA3-256, SHA3-384, SHA3-512.
Text is hashed as UTF-8. The checked algorithms are remembered between launches.

## Build

Needs JDK 21+, Maven, and (for the installer) WiX Toolset 3 on `PATH`.

```bash
mvn package                   # runs tests, builds target/hasher.jar
java -jar target/hasher.jar   # run it
```

```powershell
.\build-installer.ps1         # builds target\installer\Hasher-1.0.0.exe
```

The icon is generated by `java tools/IconGen.java` (run from the project root).
